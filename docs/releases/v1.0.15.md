# ISTUDIO v1.0.15

This release upgrades ISTUDIO's visual analysis pipeline to Gemini 3.5 while keeping dedicated Gemini image models for final image generation.

## What's Improved

- Reference DNA reading now uses Gemini 3.5 first for stronger analysis of lighting, background structure, mood, depth, and spatial layout.
- Target photo analysis and realism review now use Gemini 3.5 before falling back to earlier analysis models.
- Image generation quality stays on the dedicated Gemini image model path, with 4K-first output unchanged.
- Desktop and Netlify mobile requests continue to use the same shared Gemini payload and user API-key flow.

## Install

Download `INSTALL-ISTUDIO.bat` from this release, place it where you want ISTUDIO installed, then double-click it. Existing projects and local settings are preserved.
