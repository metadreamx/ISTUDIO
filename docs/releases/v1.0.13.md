# ISTUDIO v1.0.13

This release republishes the current ship-ready ISTUDIO build with a fresh installer package.

## What Changed

- Refreshed the Windows installer release so users get the latest packaged app files from GitHub Releases.
- Preserved the v1.0.12 production fixes: high-detail Reference Edit handling, stronger fine-detail generation instructions, local project storage, Tethered Mode, and Virtual Set.
- Kept the installer/update flow simple: users download `INSTALL-ISTUDIO.bat`, place it where they want ISTUDIO installed, and double-click it.

## Install Or Update

Download `INSTALL-ISTUDIO.bat` from this release, place it where you want ISTUDIO installed, then double-click it. Existing projects and local settings are preserved.

Users still need to provide their own Google API key for Gemini-powered editing.
