# ISTUDIO v1.0.17

This release expands Reference Edit into a more flexible professional workflow while improving output consistency, local tools, and desktop usability.

## Multi-Reference Direction

- Add one primary reference and up to three supporting reference images.
- ISTUDIO now identifies recurring lighting, palette, atmosphere, material, lens, and finishing traits across the complete reference set.
- The primary reference leads the composition and scene direction while supporting references strengthen shared style cues.
- Prompt Edit now acts as art direction for the reference set, letting users describe which image should influence the location, lighting, palette, mood, or finish.
- Multi-reference selections and prompt direction are saved with the project and restored on another computer.

## Reference Edit Improvements

- Locked generated output to the target photo's original dimensions, aspect ratio, crop, and subject placement.
- Added stronger subject-consistency, realistic-lighting, contact-shadow, edge-integration, and anti-sticker generation rules.
- Added a quality-first Gemini image model order with 4K-first output.
- Added Gemini 3.5 analysis for visual DNA reading, target analysis, and realism review, with automatic fallbacks.
- Improved large-image and batch stability through file-backed project assets and request-aware image optimization.

## New Creative Tools

- Added Color Grade for automatic reference-based palette, exposure, contrast, highlight, shadow, and tone matching without changing image structure.
- Added optional Local Pro Tools for shoot culling, cutouts, portrait cleanup, real-time finishing adjustments, and enhanced exports.
- Updated the desktop workspace and project dashboard for a denser, more professional editing workflow.

## Install Or Update

Download `INSTALL-ISTUDIO.bat`, place it in the folder where you want ISTUDIO installed, then double-click it. The installer checks for the newest release and preserves existing projects and local settings.

Users provide their own Google Gemini API key for Reference Edit generation.
