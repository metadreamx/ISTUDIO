# ISTUDIO v1.0.11

This release ships the refreshed Virtual Set workspace and makes the one-click installer self-updating.

## What Changed

- Virtual Set now opens with a cleaner starter scene: a large checker platform, one white starter box, daylight sun, and a generated blue sky sphere.
- The viewport has more working room. The Creative Library and transform toolbar can now collapse so the canvas stays clear.
- The right sidebar has been redesigned into a glassy creator control panel with large action buttons, render preset cards, collapsible sections, visual toggles, and friendlier labels.
- Render presets now update real render settings for Fast, Balanced, Ultra, Cinematic, Product, and Social workflows.
- `INSTALL-ISTUDIO.bat` now checks GitHub Releases every time it runs. If a newer installer is available, it downloads it, replaces itself, and restarts with the newest app package before launching.
- The installed `LAUNCH.bat` continues checking for updates every time ISTUDIO opens.

## Install Or Update

Download `INSTALL-ISTUDIO.bat` from this release, place it where you want ISTUDIO installed, then double-click it. Existing projects and local settings are preserved.

Users still need to provide their own Google API key for Gemini-powered editing.
