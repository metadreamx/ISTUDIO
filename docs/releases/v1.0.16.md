# ISTUDIO v1.0.16

## Local Pro AI Tools

- Added the optional **Local Pro AI Pack** for Windows desktop users.
- Added Pro Tools inside Reference Edit: Analyze Shoot, Pick Best, Transparent PNG, Clean Portrait, Finish Image, and Upscale Export.
- Added local project-backed outputs for culling reports, masks, cutouts, portrait cleanup, and finished files.
- Added Pro AI status/install APIs and release packaging for `ISTUDIO-ProTools-windows.zip`.
- Added ONNX Runtime support for local model execution with Windows GPU acceleration when available and CPU fallback.

## Notes

- Gemini Reference DNA generation is unchanged.
- The main installer stays lightweight; the Pro AI Pack is optional.
- Mobile/PWA users keep the cloud Gemini workflow and will see Local Pro AI as a Windows desktop feature.
