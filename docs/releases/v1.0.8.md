# ISTUDIO v1.0.8

This release adds Tethered Mode for Reference Edit, giving studio users a faster capture-to-edit workflow for camera sessions.

## What Changed

- Added **Tethered Mode** inside Reference Edit.
- Users can choose a camera capture folder and have new photos import into the active project automatically.
- Users can start tethering in the current project or create a new tethered session project.
- Added an **Auto Edit** toggle. New photos always import and save; when Auto Edit is on and Reference DNA controls are ready, captures queue for editing automatically.
- Added a capture tray showing imported, queued, processing, completed, ignored, and failed captures.
- Tethered captures are saved locally in the project folder under `tether/inbox`.
- The watcher waits for files to finish writing before importing, which helps with camera software that saves large photos in stages.
- RAW files are ignored with clear guidance to save JPEG, PNG, WebP, or TIFF previews from the tether software.
- Added local tether APIs and a Windows folder picker for choosing the watched capture folder.
- Reduced repeated polling payload size so imported capture images are not resent after ISTUDIO has already ingested them.
- Updated dependencies and removed an unused package; production dependency audit now reports no vulnerabilities.

## Install Or Update

Download `INSTALL-ISTUDIO.bat` from this release, place it where you want ISTUDIO installed, then double-click it. Existing projects and local settings are preserved.

Users still need to provide their own Google API key for Gemini-powered editing.
