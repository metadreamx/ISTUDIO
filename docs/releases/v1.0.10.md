# ISTUDIO v1.0.10

This hotfix polishes Tethered Mode and makes live capture sessions follow the latest imported image.

## What Changed

- Redesigned the **Auto Edit** switch so it has a proper anchored toggle, clear On/Off state, and accessible switch behavior.
- New tethered captures now become the active image automatically, so the viewport follows the latest photo as it imports.
- Multiple captures arriving together are ordered by capture/import time before being added to the project.
- Auto Edit behavior is unchanged: imported photos save immediately, and ready captures queue automatically when the switch is on.

## Install Or Update

Download `INSTALL-ISTUDIO.bat` from this release, place it where you want ISTUDIO installed, then double-click it. Existing projects and local settings are preserved.

Users still need to provide their own Google API key for Gemini-powered editing.
