# ISTUDIO v1.0.12

This release is a ship-readiness pass for Reference Edit, installer packaging, and release polish.

## What Changed

- Removed the remaining Subject Lock/SAM user-facing workflow from the app surface while keeping the stronger Reference Edit prompt quality improvements.
- Confirmed the standalone Canvas tool is not present in the app navigation or dashboard; only required internal browser canvas utilities remain for export, previews, and 3D textures.
- Improved upload handling for high-resolution camera photos, including Canon R5 C stills: ISTUDIO now preserves originals when practical, uses a larger 4K-focused working size, high-quality scaling, and less aggressive JPEG compression.
- Added stricter generation instructions to preserve fine details such as hair, eyes, teeth, fingernails, jewelry, skin texture, fabric weave, and camera sharpness.
- Removed the unused `sharp` package from the Windows release package.
- Updated public README copy for the current release flow and high-detail output behavior.

## Install Or Update

Download `INSTALL-ISTUDIO.bat` from this release, place it where you want ISTUDIO installed, then double-click it. Existing projects and local settings are preserved.

Users still need to provide their own Google API key for Gemini-powered editing.
