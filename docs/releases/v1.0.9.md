# ISTUDIO v1.0.9

This hotfix stops Tethered Mode from importing the same capture repeatedly.

## What Changed

- Tethered Mode now deduplicates captures by image content hash instead of modified time, so repeated camera software file-change events do not create duplicate imports.
- ISTUDIO now refuses to watch folders inside the local `projects` folder, preventing the app from importing its own saved tether inbox copies.
- Tethered imports now write the already-read capture buffer into the project inbox, reducing extra disk reads during import.
- The capture loop fix preserves the normal workflow: new unique camera files still import and Auto Edit can still queue them automatically.

## Install Or Update

Download `INSTALL-ISTUDIO.bat` from this release, place it where you want ISTUDIO installed, then double-click it. Existing projects and local settings are preserved.

Users still need to provide their own Google API key for Gemini-powered editing.
