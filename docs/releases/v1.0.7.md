# ISTUDIO v1.0.7

This release focuses on safer project recovery, faster project saving, and a cleaner installer/launcher flow for Windows users.

## What Changed

- Project folders are more resilient. ISTUDIO now lists and opens valid copied project folders, nested project folders, image-only folders, and folders with damaged or string-only `project.json` files.
- A bad project file no longer blocks the whole Projects dashboard.
- Missing image files or old paths from another computer no longer hide the project.
- Reference Edit now saves immediately when users upload a reference photo, target photos, or custom clothing/accessory/face/background/sky assets.
- Legacy design tool data now saves immediately when users import or replace an image.
- Virtual Set now uses a native ISTUDIO 3D engine with PBR materials, lights, environment controls, GLB/image imports, and beauty rendering.
- The public download remains `INSTALL-ISTUDIO.bat`.
- The installed app launcher inside the `ISTUDIO` folder is now `LAUNCH.bat`.

## Install Or Update

Download `INSTALL-ISTUDIO.bat` from this release, place it where you want ISTUDIO installed, then double-click it. Existing projects and local settings are preserved.

Users still need to provide their own Google API key for Gemini-powered editing.
