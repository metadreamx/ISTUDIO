# ISTUDIO v1.0.14

This hotfix focuses on Reference Edit batch stability and memory use for large camera files.

## What changed

- Reference and target uploads now save into the local project folder immediately instead of staying in long-lived browser memory.
- Project reloads now use local asset URLs, so ISTUDIO no longer hydrates every full-resolution image into base64 at startup.
- Batch uploads process sequentially with a Smart Balanced input cap to avoid runaway memory growth on regular Windows computers.
- Gemini requests now load only the active image assets just in time, then release them after the request completes.
- Generated outputs save directly to `outputs/`, and generation history stores lightweight project-backed image links.
- Legacy projects with embedded base64 images are converted into project asset files when opened and saved.
- Export and preview flows now work from project-backed asset URLs instead of requiring in-memory base64 images.

## Install

Download `INSTALL-ISTUDIO.bat` from this release, place it where you want ISTUDIO installed, then double-click it. Existing projects and local settings are preserved.
